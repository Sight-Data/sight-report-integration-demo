接入总览与签名规则

          

        

        

          
四类场景

          
    
            
  • 嵌入查看 — embed.html?reportId={id}&_s={signature}
    • 
            
  • 接收事件 — 宿主 window.addEventListener('message', ...)
    • 
            
  • 获取报表列表 — /api/embed/report/type-tree、/api/embed/report/tag-list
    • 
            
  • 服务端导出 — /api/embed/export/{pdf|excel|word|csv}
    • 
          


          
签名规则

          
    
            
  • 签名内容：appId | account | userName | reportId | expireAt（竖线连接）
    • 
            
  • 算法：HMAC-SHA256(签名内容, appSecret)，输出十六进制
    • 
            
  • 参数体：上述字段 + signature 组成 JSON，再 Base64Url 编码（无填充），作为 _s
    • 
            
  • expireAt 是 Unix 秒；查看类建议 5~15 分钟，每次打开实时生成，不要缓存 URL
    • 
          


          
reportId 绑定规则

          
    
            
  • 查看报表：建议绑定具体 reportId
    • 
            
  • 获取列表：通常留空，返回应用白名单范围内全部结果
    • 
            
  • 服务端导出：必须与请求参数 fileId 完全一致，不可留空
    • 
          


          
务必注意

          
    
            
  • appSecret 只在服务端使用，不可下发到浏览器或客户端
    • 
            
  • 外部用户会映射为内部用户，格式 ext__{appId}__{account}
    • 
            
  • 配置「报表白名单」后，列表接口也会自动受限，第三方无需再过滤
    • 
          

        

      

    


    
    

      

        

          
报表事件 — 接入说明

          

        

        

          
事件分两级

          
    
            
  • 
              零配置直发：report:loaded（首次渲染完成，payload { elapsedMs }）、
              report:error（payload { phase, message }）、
              单元格事件（设计器「发送事件」链接配置）
            
    • 
            
  • 
              订阅后才发：report:query、report:query-done、
              report:export、report:print
            
    • 
          


          
第一步：零配置监听

          
window.addEventListener('message', (e) => {
  if (e.origin !== 'https://报表系统地址') return   // 校验来源
  if (e.data?.protocol !== 'sight-report') return   // 校验协议命名空间
  const { name, payload, source } = e.data
  // source = { reportId, cellName?, cid? }，cid 形如 "A2-3-1" 可区分展开后第几行
})


          
第二步（可选）：订阅过程性事件

          
iframe.contentWindow.postMessage({
  protocol: 'sight-report',
  type: 'subscribe',
  events: ['report:query', 'report:export']   // 或 ['*']
}, 'https://报表系统地址')

          
订阅同时会让报表侧锁定本页面 origin 作为后续 postMessage 的 targetOrigin（安全收紧）。


          
单元格事件怎么配

          
    
            
  1. 报表设计器 → 选中单元格 → 链接 → 添加链接 → 发送事件
    2. 
            
  2. 事件名自定义（如 order-selected），不能以 report: 开头
    3. 
            
  3. 参数作为 payload 传出，支持表达式（如 A2 取当前行单元格值）
    4. 
          

        

      

    


    
    

      

        

          
外部数据集 — 接入说明

          

        

        

          
使用流程

          
    
            
  1. 上传数据 — 后端调 POST /api/embed/staged-dataset/set，返回 token
    2. 
            
  2. 嵌入 / 导出 — parameters 里加 "_dataIds": "<token>"
    3. 
            
  3. 清除（可选） — POST /api/embed/staged-dataset/clear
    4. 
          


          
请求与响应

          
POST /api/embed/staged-dataset/set
{
  "signature": "<签名 token>",
  "reportId": "rpt_sales",
  "datasets": { "orders": [ { "orderId": "ORD-001", "price": 99.5 } ] }
}

→ { "code": 0, "data": { "token": "a1b2c3d4", "datasetNames": ["orders"] } }


          
注意事项

          
    
            
  • 签名方式与嵌入报表相同（HMAC-SHA256）
    • 
            
  • 一次请求可传多个数据集，共享一个 token；每次 /set 生成新 token，不支持追加
    • 
            
  • 数据默认保留 24 小时，payload 上限 5 MB
    • 
            
  • 报表设计时需先创建「外部数据集」并定义字段结构
    •
